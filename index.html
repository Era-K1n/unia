Зачем

Компьютер, который слушается голоса

Управлять Windows мышью и клавиатурой не всегда удобно и не всегда возможно — например, при ограниченной моторике или зрении. Готовые голосовые помощники решают это через облако: голос и данные уходят на чужой сервер. U.N.I.A. — попытка сделать то же самое локально: своя языковая модель, свой голос, свои глаза для экрана — всё на одном компьютере, без интернета.

Идея выросла из фильмов про Железного человека — хотелось своего Джарвиса, который не просто болтает, а реально управляет компьютером. Концепцию, архитектуру действий и все механики автор придумал и собрал сам: несмотря на волну похожих самодельных ассистентов в TikTok и Shorts за последний год, ни разработка, ни решения этого проекта не копировались.

Ключевые фичи

Что реально решает системные проблемы

Ниже — только рабочие механики проекта, с короткими фрагментами кода там, где решение нестандартное.

01

Фильтр эха по совпадению слов

Динамики озвучивают ответ, а микрофон слышит его снова — это ложная команда. Система сравнивает слова из микрофона с последней фразой ассистента; при совпадении ≥25% команда аннулируется, а контекст диалога обнуляется, чтобы модель не «зациклилась».

overlap = len(mic_words & ai_words)
score = overlap / len(mic_words)
if score >= 0.25: command = ""
02

Зрение экрана

EasyOCR распознаёт текст с экрана — код, ошибки, статьи. Локальная модель разбирает результат: находит опечатки в именах переменных по PEP 8, объясняет содержимое, если это не код.

03

Двухконтурное завершение процессов

Закрытие программы бьёт по цели два раза подряд: первый контур — по имени процесса во всём дереве, второй — точечно по PID, найденному через сопоставление слов команды со списком запущенных процессов.

04

Конструктор своих команд

Через визуальный редактор пользователь сам привязывает голосовую фразу к цепочке действий: запуск программы, закрытие процесса, открытие сайта, клик по координатам, голосовая реплика — без единой строки кода.

05

Открытие чего угодно по имени

«Открой файл тест», «запусти Need for Speed», «открывай папку загрузки» — ассистент ищет совпадение не по жёсткому списку путей, а нечётким сравнением слов среди всех ярлыков Windows и файлов на диске, включая OneDrive. Работает для абсолютно любых файлов, папок и установленных приложений — гибкость, а не список из десяти заранее вбитых программ.

06

Своя модель поверх Qwen2.5, а не чужой API

Мозг ассистента — модель unia: кастомная сборка Qwen2.5:7b в Ollama с собственным системным промптом, строгой JSON-грамматикой действий и примерами диалогов под формат U.N.I.A. Сами веса модели не менялись — это настройка поведения, а не обучение с нуля. Благодаря этому модель обязана отвечать структурированным JSON с полями action / query / reply и никогда не выходить за рамки заданного списка действий — ассистент предсказуем и работает без единого обращения к внешним ИИ-сервисам. Следующий шаг в планах — настоящее дообучение весов под unia (см. «Планы» ниже).

Чем это отличается

Не обёртка над чат-ботом, а контроллер

Большинство самодельных голосовых ассистентов — это микрофон, запрос к облачному API и десяток жёстко прописанных команд вида «если услышал слово X — сделай Y». U.N.I.A. устроена иначе, и вот в чём разница на уровне механики, а не маркетинга:

Грамматика вместо догадок

Модель обязана вернуть один из заранее заданных типов действия в строгом JSON, а не свободный текст, который потом пытаются распарсить — отсюда предсказуемость и отсутствие случайных действий.

Нечёткий поиск, не хардкод

Запуск и поиск файлов работает через пересечение множеств слов (коэффициент Жаккара) по всей базе ярлыков и диску, а не по списку из десяти заранее вбитых программ.

Видит и объясняет экран

OCR-зрение с разбором кода по PEP 8 — большинство голосовых ассистентов такого уровня вообще не смотрят на экран.

Нет облака вообще

Распознавание, синтез речи и ИИ-логика считаются на том же компьютере — ни голос, ни команды никуда не уходят, кроме самого шага распознавания речи.

Настоящее дообучение unia

Перейти от системного промпта к реальному fine-tuning весов (LoRA) на собственном датасете голосовых команд — чтобы unia была моделью не только по названию.

Локальное распознавание речи

Заменить облачное распознавание на локальный движок (например Vosk или Whisper), чтобы голос не покидал компьютер совсем.

Клонирование голоса

Запись короткого образца речи и синтез ответов этим голосом через XTTS — четвёртый, персональный голос ассистента.
